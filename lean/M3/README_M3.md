# 45a M3: the T(c) bound from a certified prime list (N version, v2)

New files on top of the statement files `Romanoff/Defs.lean` and `Romanoff/TBoundSpec.lean`, which are unchanged. Toolchain v4.35.0-rc3, Mathlib c55e6e786f49.

## Statement
```lean
def Romanoff.M3.teffCert : List ℚ := R45.M3.teffD R45.M3.D.data
theorem Romanoff.M3.tboundCert (h5 : R0Bound) : TBound teffCert
theorem Romanoff.M3.teffCert_eq : teffCert = R45.M3.teffLit       -- 120 literal rationals, RCert/M3/TeffLit.lean
theorem Romanoff.M3.tboundLit (h5 : R0Bound) : TBound R45.M3.teffLit
theorem Romanoff.M3.tbound_of (D : Data) (hD : certOK D = true) (hs : sumsOK D (runDP tab0 D.gA) = true)
    (h5 : R0Bound) : TBound (teffOf D (runDP tab0 D.gA) (runDrop tab0 D.gA) (runDP (runDP tab0 D.gA) D.gE) (bsOf D ...))
```
`#print axioms`: `tbound_of`: propext, Classical.choice, Quot.sound. `tboundCert`: these plus the native_decide axioms of
`certOK_data`, `sumsOK_data`; `tboundLit` also `teffD_eq` (all three in `RCert/M3/NCheck.lean`).

## Method
`teff(c) = (T_a(c) + prune(c) + T_b(c)) / 2^64 + gcd(c, 120) · R0tail`, `R0tail = 1.93656 - (R0a + R0b) / 2^64`.
* Certificates: 717 primes of order <= 300 (gA: not dividing ell; gE: the 9 primes of ell), 3,103 primes of order in
  (300, 1200] (gB), every prime >= 2^16 by a Pratt record (12,639 records: p - 1 = prod q^e, witness a, factors >= 2^16
  are records themselves; Mathlib `lucas_primality`), primes < 2^16 by trial division; exact orders by 2^t = 1 and
  2^(t/r) != 1 mod p for the primes r of t (`orderOf_eq_of_pow_and_pow_div_prime`). Group orders distinct, primes
  sorted within groups, so all primes are distinct. Dropped (uncertified, in the rest class): 4 primes of order <= 300,
  all > 5e61, and 128 of order in (300, 1200], all > 1e49.
* Classes for m odd, squarefree, coprime to ell: (a') all prime factors in gA; (b') m = q m' with q in gB and all prime
  factors of m' in gA; (c') the rest, bounded by gcd(c, 120) Σ fm/ordm and `R0Bound` on (c') ∪ prodSet(gA ∪ gE) ∪
  q · prodSet(gA ∪ gE) (pairwise disjoint), whose sums are bounded below from the R0 table.
* `Fs xs φ = Σ_{s ⊆ xs} f(s) φ(lcm of orders)`, `Fs (x :: xs) φ = Fs xs φ + f(x) Fs xs (φ ∘ lcm t_x)`;
  `Σ_{m ∈ S} fm m φ(ordm m) ≤ Fs xs φ` for squarefree m with prime factors in xs (`ordm (a b) = lcm` by CRT).
* DP over the groups of gA (289 orders), fixed point 2^64, entries (L, lower, upper), cut at LMAX = 3,000,000:
  pruning is exact for functions vanishing above LMAX; the pruned part is bounded by
  (∏ (1 + f) - Σ lower) · gcd(c, 120)/LMAX (pruned mass 2.13e-3). After each step, entries with upper weight
  b < 16384 · L are dropped (`keepE`); their mass D = Σ ⌈b/L⌉ (2.05e-11) enters as gcd(c, 120) · ∏ · D (`drC`),
  since a dropped entry contributes at most b · gcd(c, 120)/L · ∏ (`keep_up`); lower bounds just lose it.
  T table 98,913 entries, R0 table (with gE) 118,063.
* Class B: 687 groups by one pass over the T table each (16 accumulators by gcd(lcm, 120)), 198 groups with
  Σ 1/(q-2) < 1e-12 by the crude bounds lcm(L, t) >= t (T) and lcm(L, t) <= t L (R0).

## Values

R0tail = 1.9583334596e-4 (paper: 1.9583327835e-4). Identical to the Python reference `M3/tools/m3ref.py` with KAPPA=16384
